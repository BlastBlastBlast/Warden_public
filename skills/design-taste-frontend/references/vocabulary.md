# Pattern Vocabulary

Names for the design/motion patterns this skill discusses, so they can be reached for by name in conversation or code comments. This is a vocabulary, not an implementation library — code sketches for the scroll-driven ones live in `references/skeletons.md`.

## Hero paradigms
- **Asymmetric Split Hero** — text on one side, asset on the other, generous white space.
- **Editorial Manifesto Hero** — large type, no asset, almost a poster.
- **Video / Media Mask Hero** — type cut out as a mask over a video background.
- **Kinetic-Type Hero** — animated typography as the primary visual.
- **Curtain-Reveal Hero** — hero parts on scroll like a curtain.
- **Scroll-Pinned Hero** — hero stays pinned while content scrolls behind it.

## Navigation & menus
- **Mac OS Dock Magnification** — edge nav, icons scale fluidly on hover.
- **Magnetic Button** — pulls toward the cursor.
- **Gooey Menu** — sub-items detach like viscous liquid.
- **Dynamic Island** — morphing pill for status/alerts.
- **Contextual Radial Menu** — circular menu expanding at the click point.
- **Floating Speed Dial** — FAB springing into curved secondary actions.
- **Mega Menu Reveal** — full-screen dropdown, stagger-fade content.

## Layout & grids
- **Bento Grid** — asymmetric tile grouping (Apple Control Center style).
- **Masonry Layout** — staggered grid, no fixed row height.
- **Chroma Grid** — borders/tiles with subtle animating gradients.
- **Split-Screen Scroll** — two halves sliding in opposite directions.
- **Sticky-Stack Sections** — sections that pin and stack on scroll.

## Cards & containers
- **Parallax Tilt Card** — 3D tilt tracking mouse coordinates.
- **Spotlight Border Card** — borders illuminate under the cursor.
- **Glassmorphism Panel** — frosted glass with inner refraction.
- **Holographic Foil Card** — iridescent rainbow shift on hover.
- **Tinder Swipe Stack** — physical card stack, swipe-away.
- **Morphing Modal** — a button expands into its own dialog.

## Scroll animations
- **Sticky Scroll Stack** — cards stick and physically stack.
- **Horizontal Scroll Hijack** — vertical scroll converted to a horizontal pan.
- **Locomotive / Sequence Scroll** — a video or 3D sequence tied to the scrollbar.
- **Zoom Parallax** — a central background image zooming on scroll.
- **Scroll Progress Path** — an SVG line drawing itself along scroll.
- **Liquid Swipe Transition** — a page transition like viscous liquid.

## Galleries & media
- **Dome Gallery** — 3D panoramic gallery.
- **Coverflow Carousel** — 3D carousel with angled edges.
- **Drag-to-Pan Grid** — a boundless draggable canvas.
- **Accordion Image Slider** — narrow strips expanding on hover.
- **Hover Image Trail** — an image trail popping where the mouse has been.
- **Glitch Effect Image** — RGB-channel shift on hover.

## Typography & text
- **Kinetic Marquee** — endless text bands reversing on scroll.
- **Text Mask Reveal** — massive type as a transparent window onto video.
- **Text Scramble Effect** — matrix-style decoding on load/hover.
- **Circular Text Path** — text curving along a spinning circle.
- **Gradient Stroke Animation** — outlined text with a running gradient.
- **Kinetic Typography Grid** — letters dodging the cursor.

## Micro-interactions & effects
- **Particle Explosion Button** — a CTA shatters into particles on success.
- **Liquid Pull-to-Refresh** — a reload indicator like detaching droplets.
- **Skeleton Shimmer** — a shifting light reflection across placeholders.
- **Directional Hover-Aware Button** — fill enters from the cursor's exact side.
- **Ripple Click Effect** — a wave from the click coordinates.
- **Animated SVG Line Drawing** — vectors drawing themselves in real time.
- **Mesh Gradient Background** — organic lava-lamp blobs.
- **Lens Blur Depth** — background UI blurred to focus the foreground action.
